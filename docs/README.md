# flavfinder-core documentation

**Languages:** [English](./en/index.md) · [简体中文](./zh-CN/index.md)

This documentation is organized for progressive disclosure:

1. **Start** — install and run a small end-to-end example.
2. **Use** — prepare data, preprocess, train, predict, and evaluate.
3. **Understand** — method, thresholds, leakage, and limitations.
4. **Reference** — CLI, Python API, configuration, and troubleshooting.

The repository contains **code only**. Training data, real example spectra, and
pretrained models are not included. See [`NOTICE`](../NOTICE) for provenance.
